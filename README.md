# 重慶八日行程

2026/09/11—09/18，從成都送爸媽搭機後前往重慶，七晚住解放碑，中間安排休息日，回程依機票彈性決定。

## 本機預覽

在此資料夾執行：

```powershell
node server.mjs
```

再開啟 `http://127.0.0.1:4317/`。

## GitHub Pages

把本資料夾內的檔案放到新 repository 根目錄，於 GitHub 的 **Settings → Pages** 選擇從主要分支根目錄部署即可。`.nojekyll` 已包含在專案中。
