# 重慶七日行程

2026/09/11—09/17，從成都送爸媽搭機後前往重慶，六晚住解放碑；目前預計 9/17 搭澳門航空從重慶經澳門轉機回高雄。

## 本機預覽

在此資料夾執行：

```powershell
node server.mjs
```

再開啟 `http://127.0.0.1:4317/`。

## GitHub Pages

把本資料夾內的檔案放到新 repository 根目錄，於 GitHub 的 **Settings → Pages** 選擇從主要分支根目錄部署即可。`.nojekyll` 已包含在專案中。
